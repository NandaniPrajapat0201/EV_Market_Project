# 🚗 EV Market Dashboard

A Flask web application that displays an interactive **Electric Vehicle Market Performance** dashboard built on Tableau Public, along with key KPIs and data-driven insights.

## 📊 Overview

This project visualizes EV market data across **7 regions** and **7 vehicle categories**, covering metrics like annual sales, battery types, and customer ratings.

## 📈 Key Metrics

| KPI | Value |
|-----|-------|
| Total Annual Sales | 1.55B units |
| Average Range | 324.5 km |
| Average Customer Rating | 4.09 |

## 📝 Insights

- All seven market regions sell roughly 217M–222M units each — no single region dominates.
- Two-Wheeler Scooters are the top-selling category in every region.
- NMC (33.8%) and LFP (32.0%) batteries make up ~2/3 of sales.
- Annual sales stay in a narrow band across years, suggesting a stable market.
